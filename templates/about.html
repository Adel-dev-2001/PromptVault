About PromptVault

Prompt Library & Image Asset Manager

About this project

PromptVault was created by Adel Mohamed as a CS50x Final Project. It stores image files alongside the exact prompt text, negative prompts, and settings used to generate them, organized into categories with pagination, search, favorites filtering, and clipboard copy.

PromptVault intentionally does not generate images, call external model APIs, or provide multi-user accounts.

Implemented Features

Paginated gallery (24/page) with ?q= search and filters
CSRF tokens and Pillow image verification
Clipboard copy and focus-trapped detail modal
JSON-LD metadata, robots.txt, and XML sitemap

Security Model

  • Single-user default: PromptVault runs locally without user accounts; setting APP_PASSWORD requires HTTP Basic auth (username ignored) on all routes except /robots.txt and /static/.
  • CSRF protection: All mutating endpoints check signed Flask-WTF CSRF tokens.
  • Upload bounds: Requests are capped at 10 MB; Pillow verifies image format against extension and checks every frame against a 20-megapixel ceiling.
  • Path checks: Category names are NFC-normalized and limited to 1-30 chars of Unicode letters, combining marks, digits, space, -, _, ZWNJ, and ZWJ; file resolution checks os.path.commonpath inside static/uploads/.
  • CSP and caching: Sends Content-Security-Policy with script-src 'self' and img-src 'self' data: blob:, Cache-Control: no-store on HTML form pages, and HSTS over HTTPS.

Stack

Python 3.11-3.13 Flask 3.1.3 SQLite 3 Pillow 13.0 Flask-WTF 1.3 Jinja2 HTML5 / CSS3

Known Limitations

Do not expose this server directly to the public internet without APP_PASSWORD and a TLS reverse proxy (TRUST_PROXY=1). No rate limiting or multi-user authorization is built in, and direct /static/uploads/ paths stay exempt with /static/.
