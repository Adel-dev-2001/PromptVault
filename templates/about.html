About PromptVault

Enterprise-Grade AI Prompt Library & Generative Asset Management System

Project Overview

PromptVault addresses a fundamental metadata persistence problem in generative artificial intelligence workflows: while modern diffusion models and multimodal generative pipelines synthesize high-fidelity visual artwork, the complex prompt engineering parameters (negative prompts, weights, tokens, and model settings) that produced them are frequently lost.

PromptVault provides a unified, secure digital vault for cataloging, categorizing, and retrieving AI-generated artwork alongside its underlying prompt engineering specifications.

Core Capabilities

Live search across prompts and category taxonomies
Defense-in-depth upload validation & CSRF protection
One-click clipboard prompt synchronization
Schema.org JSON-LD & automated XML sitemaps

Security Architecture

  • CSRF Mitigation: All state-altering endpoints require cryptographically signed CSRF tokens via Flask-WTF.
  • Deep File Verification: Inbound uploads undergo dual-phase verification via Werkzeug file sanitization and Pillow deep header analysis to prevent polyglot payloads.
  • Decompression Bomb Protection: Pixel count is strictly capped at 20 megapixels and total payload to 10 MB.
  • Path Traversal Immunity: Storage and download paths are verified using canonical path containment checks.
  • Strict Security Headers: Enforces Content-Security-Policy (CSP), X-Content-Type-Options (nosniff), X-Frame-Options (SAMEORIGIN), and strict Referrer-Policy.

Technology Stack

Python 3.13+ Flask 3.x SQLite3 (WAL & Indexed) Pillow (PIL) Flask-WTF Jinja2 HTML5 / CSS3 Schema.org JSON-LD
