About PromptVault

AI Prompt Library & Image Asset Manager

Project Overview

PromptVault solves a common problem in generative AI workflows: while image generation models produce detailed visual artwork, the exact prompts, negative prompts, and parameters used to create them are easily lost over time.

PromptVault provides a clean web library for uploading AI-generated images, saving the exact prompts behind them, and organizing everything by category.

Core Capabilities

Live search across prompts and categories
Strict image validation & CSRF protection
One-click clipboard prompt copy
Schema.org JSON-LD & XML sitemap

Security Architecture

  • CSRF Protection: All state-changing endpoints in the Flask backend require signed CSRF tokens via Flask-WTF.
  • Deep Image Verification: Uploaded files are sanitized with Werkzeug and inspected with Pillow to confirm the binary header matches the file extension.
  • Upload & Pixel Limits: Requests are capped at 10 MB and image dimensions are limited to 20 megapixels to prevent decompression bombs.
  • Path Traversal Protection: File storage and download routes verify canonical paths to ensure files remain strictly inside the uploads directory.
  • HTTP Security Headers: Enforces Content-Security-Policy (CSP), X-Content-Type-Options (nosniff), X-Frame-Options (SAMEORIGIN), and strict Referrer-Policy.

Technology Stack

Python 3.13+ Flask 3.x SQLite 3 Pillow (PIL) Flask-WTF Jinja2 HTML5 / CSS3 Schema.org JSON-LD
