    About PromptVault

    Prompt Library & Image Asset Manager

    About this project

    PromptVault was created as a CS50x Final Project by Adel Mohamed to keep generated images paired with the prompts used to create them. It organizes saved entries by category with search, favorites filtering, clipboard copy, and image downloads.

    It intentionally does not generate images or manage multi-user accounts.

    Static Demo vs Flask App

    This GitHub Pages page runs purely in your browser using localStorage and has no backend database. Storage is local to the current browser and limited by browser quota. For disk storage under data/uploads/, SQLite queries, CSRF protection, and server-side Pillow verification, run the Flask application from the repository.

    Flask Stack

    Python 3.11-3.13 Flask 3.1.3 SQLite 3 Pillow 13.0 Flask-WTF 1.3 HTML5 / CSS3
